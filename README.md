# Claymore Law Event Timer (CLE)

Guild Wars 2 icin Nexus addonu: world boss, meta event, convergence, ley-line anomaly ve dragonstorm zamanlamalarini expansion bazli gruplar halinde gosterir.

## Kurulum

1. [Nexus](https://raidcore.gg/Nexus) kurulu olmali.
2. [Releases](../../releases/latest) sayfasindan `claymore-event-timer.dll` dosyasini indirip oyunun `addons/` klasorune kopyalayin (veya Nexus'tan yukleyin).
3. Oyunda **ALT+E** ile pencereyi acin (Nexus Quick Access'te CLE ikonu da var).

Guncellemeler Nexus uzerinden otomatik gelir.

## Ozellikler

- **Expansion bazli gruplama**: Core Tyria, Heart of Thorns, Path of Fire, Icebrood Saga, End of Dragons, Secrets of the Obscure, Janthir Wilds, Visions of Eternity
- **5 kategori**: World Boss, Meta Event, Convergence, Ley-Line Anomaly, Dragonstorm
- **Chatlink kopyalama**: Satira tiklayarak waypoint kodunu panoya kopyalayabilirsiniz
- **Bildirimler**: Yaklasan eventler icin toast bildirimi
- **Per-event toggle**: Ayarlardan istemediginiz eventleri kapatabilirsiniz
- **UTC + yerel saat**

## Veri Kaynagi

Event zamanlama verisi GW2 Wiki'nin `Widget:Event_timer/data.json` dosyasindan gelir (oyun ici `/wiki et` ile ayni veri).

## Not

Bu repo sadece surumleri (DLL) dagitmak icindir. Hata bildirimi icin [Issues](../../issues) kullanabilirsiniz.
